[ Append-Only Event Store ]

[ NodeJS ]

[ Express ]

This project is a simple event store built with Node.js and Express. Instead of using a traditional database, events are written as JSON objects to an append-only log file called events.log. An in-memory index maps each event ID to its byte offset and length, enabling O(1) reads without scanning the entire file. When the server restarts, it rebuilds the index from the log file.
