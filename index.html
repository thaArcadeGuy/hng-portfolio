Featured Project

Append-Only Event Store

Append-Only Event Store is a lightweight service that stores events in an append-only log and rebuilds its in-memory index on startup for fast lookups and recovery.

Problem Solved

Built a lightweight event store that persists data without a traditional database, ensuring events survive server restarts through an append-only log file.

Architecture / Request Flow

Events are appended to events.log and indexed in memory using byte offsets. Reads use the index to jump directly to the event's location in the file, avoiding full-file scans.

Key Endpoints

  • POST /events — Create and store an event.
  • GET /events/:id — Retrieve an event by ID.
  • GET /stats — View event count and log size.

Technical Challenge

Accurately tracking byte offsets and event lengths for direct file reads, especially during startup recovery. Solved by rebuilding the in-memory index from the log file and using UTF-8 byte calculations for every event.
